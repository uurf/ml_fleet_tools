Required Manual Headset Settings
Complete all steps in order · move to next device when done
KAGAMI / Tin Drum
Controller
Connect controller to Compute Pack via USB-C
Put on headset briefly — a firmware update screen will appear. You don't need to keep the headset on. The controller LED will flash white while updating; you'll hear a sound when complete (~2 min). Disconnect the cable when done.
Laptop connection
Reconnect Compute Pack to laptop via USB-C
Two dialogs will appear — put on headset to dismiss them:
Allow USB debugging — check "Always allow from this computer" → tap Allow
USB Device Detected — tap OK
Battery
Settings → Battery → Compute Pack Standby
Toggle off
Off
Display
Settings → Display → Display Override
Toggle off
Off
Settings → Display → Global Dimming
Adjust slider to just below maximum — even with the h in the word "light" in the paragraph below the setting
Settings → Display → Segmented Dimming
Toggle on
On
Settings → Display → Maximum Dimming
Adjust slider to just below maximum — even with the l in the word "display" in the paragraph above the setting
System
Settings → System → Advanced → OS Updater
Set check frequency to Never
Never
Shut down device
Hold Power until the shutdown screen appears — confirm shutdown. Only place in foam case after the fan has stopped.

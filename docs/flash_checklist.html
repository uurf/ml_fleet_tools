Flash & provision checklist
Per device · laptop must be plugged in · see PROVISIONING.md for full instructions
KAGAMI / Tin Drum
Before you start
Laptop is plugged in to power
USB suspend during flash will corrupt the device
KAGAMI WiFi network is broadcasting nearby
SSID: KAGAMI  ·  Password: KAGAmius
Active show is set on this laptop
Run ./ml_show.sh — it should report Active show: KAGAMI. If not set: ./ml_show.sh use KAGAMI (or ask your team lead which show this laptop is for).
Device number and case number for Google tracking sheet
Put device into fastboot
Power off the device
Hold Power until it shuts down completely
Boot into fastboot mode
Hold Volume Down + press Power — wait for fastboot LED on Compute Pack
Connect Compute Pack to laptop via USB-C
Flash & provision
Open Terminal and navigate to toolkit
cd ~/Developer/ml_toolkit
Run flash script
./ml_os_flash.sh
Type the show id to confirm, then enter device info
The script prints the show (e.g. Show: KAGAMI) and asks you to type the show id — type KAGAMI and press Enter. (Wrong id, or the wrong show: Ctrl+C and tell your team lead.)
Then: device number · case number · operator initials
Script runs unattended for ~10 min after this — you can walk away
Wait for "Provisioning complete"
Flash ~10 min · provision ~2 min · sheet updated automatically
Serial number is copied to clipboard when done
Now continue with the Required Manual Headset Settings Checklist.

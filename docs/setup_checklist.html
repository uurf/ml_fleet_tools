Machine setup checklist
マシンセットアップ・チェックリスト

ラップトップごとに1回のセットアップ・詳細は SETUP.md を参照
KAGAMI / Tin Drum
Before you start 開始前の準備
Mac with a free USB-C port while plugged in to power
電源に接続した状態で、空きの USB-C ポートがある Mac が必要
Fleet ADB key file from your team lead
adbkey_kagami_fleet — every machine connecting to fleet devices must use this key
チームリーダーからフリート ADB キーファイルを受け取る
adbkey_kagami_fleet — フリートデバイスに接続するすべてのマシンでこの ADB キーファイルを使用する必要があります
Internet connection
インターネット接続
Install インストール
Open Terminal
Press Cmd+Space, type Terminal, press Enter
ターミナルを開く
Cmd+Space を押し、Terminal と入力して Enter を押す
Run the installer
curl -fsSL https://raw.githubusercontent.com/uurf/ml_fleet_tools/main/install.sh | bash
Enter your Mac password if prompted. It installs the tools and clones the toolkit, then pauses to ask for the fleet key (next step).
インストーラーを実行
curl -fsSL https://raw.githubusercontent.com/uurf/ml_fleet_tools/main/install.sh | bash
求められたら Mac のパスワードを入力。ツールをインストールしツールキットをクローンした後、フリートキーの入力待ちで一時停止します（次のステップ）。
Fleet ADB key フリート ADB キー
When prompted, add the fleet key
Get adbkey_kagami_fleet from your team lead and copy it into:
~/Developer/ml_toolkit/authorized_keys/
Then press Enter. The installer activates the key and finishes with Installation complete!
プロンプトが表示されたらフリートキーを追加
チームリーダーから adbkey_kagami_fleet を受け取り、次の場所にコピーしてください:
~/Developer/ml_toolkit/authorized_keys/
その後 Enter を押す。インストーラーがキーを有効化し、Installation complete! と表示されて完了します。
Don't have the key yet? (fallback)
Type s at the prompt to skip.
Later, place adbkey_kagami_fleet at the path above and run cd ~/Developer/ml_toolkit && ./install.sh to finish. Look for Fleet ADB key installed.
まだキーが無い場合（暫定対応）
プロンプトで s を入力してスキップしてください。
後で adbkey_kagami_fleet を上記のパスに配置し、cd ~/Developer/ml_toolkit && ./install.sh を実行して完了。Fleet ADB key installed の表示を確認。
OS image Optional OS イメージ 任意
Only needed if you will flash devices to a clean, factory MLOS state. Most operators can skip this section — flashing is occasional and only for specific problem devices.
デバイスを工場出荷時のクリーンな MLOS 状態にフラッシュする場合のみ必要。ほとんどのオペレーターはこのセクションをスキップできます — フラッシュは特定の問題のあるデバイスに対してのみ行う作業です。
Download OS image from Magic Leap Hub
Package Manager → Device OS Versions → select version → Apply Changes → wait → Open Folder
Magic Leap Hub から OS イメージをダウンロード
Package Manager → Device OS Versions → バージョンを選択 → Apply Changes → 待機 → Open Folder
Copy image folder to toolkit and rename to version number
~/Developer/ml_toolkit/os_images/1.4.1/
Folder must contain flashall_amd.sh and *.img files
イメージフォルダをツールキットにコピーし、バージョン番号にリネーム
~/Developer/ml_toolkit/os_images/1.4.1/
フォルダには flashall_amd.sh と *.img ファイルが含まれている必要があります。
Select the show ショーを選択
Set the active show for this laptop
One-time per machine. Your team lead tells you which show — for the main show:
cd ~/Developer/ml_toolkit && ./ml_show.sh use KAGAMI
Confirm with ./ml_show.sh — should report Active show: KAGAMI. Until this is set, every flash/provision/deploy command stops with a "no show configured" error.
このラップトップのアクティブショーを設定
マシンごとに1回。どのショーかはチームリーダーが指示します — メインショーの場合:
cd ~/Developer/ml_toolkit && ./ml_show.sh use KAGAMI
./ml_show.sh を実行して確認 — Active show: KAGAMI と表示されれば正常です。設定が完了するまで、flash/provision/deploy の各コマンドは "no show configured" エラーで停止します。
Verify 確認
Run flash script to confirm setup
cd ~/Developer/ml_toolkit && ./ml_os_flash.sh
With the show set and no device connected, it prints the show banner then stops at No device found over USB — that's success, not an error. A "no show configured" or "out of date" message means the step above (or the toolkit) still needs attention.
フラッシュスクリプトを実行してセットアップを確認
cd ~/Developer/ml_toolkit && ./ml_os_flash.sh
ショーが設定され、デバイス未接続の状態では、ショーバナーを表示後 No device found over USB で停止します — これはエラーではなく成功です。"no show configured" や "out of date" のメッセージが出る場合は、上記の手順（またはツールキット）の対応がまだ必要です。
To update the toolkit later: cd ~/Developer/ml_toolkit && ./update.sh
If a script tells you to update when you run it, this is the command to use.
後でツールキットを更新するには: cd ~/Developer/ml_toolkit && ./update.sh
実行時にスクリプトが更新を求めてきた場合は、このコマンドを使用してください。
